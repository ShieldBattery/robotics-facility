The original README and source author notices are preserved in this download.

Modified by ShieldBattery on 2026-09-23:
- Port the terrain API to source-built BWTA2, including an integer polygon
  containment helper with an explicit boundary-inside rule.
- Run the module in a BWAPI 4.4 external client, using the static MSVC runtime.
  The process exits after one completed match or bridge disconnection.
- Perform terrain initialization before adding initial units to the agent graph.
- Replace the unsafe background pathfinding worker with at most one queued
  path calculation per game callback. Individual queries are not time-limited.
- Make module cleanup unconditional and idempotent, correct singleton and squad
  ownership, and free exploration records during shutdown.
- Disable user input, chat commands and output, speed changes, debug overlays,
  and the bot's fixed-time match termination.
- Disable strategy history, statistics and profiling storage. Every match uses
  the upstream strategy chosen for empty history; this package does not learn.
- Remove BWTA2 terrain cache/log writes and obsolete cache serializers. Build
  only its Release terrain library, without offline or debug-drawing features.
- Remove BWTA2's unused obsolete Boost dissolve include and build with the
  verified Boost 1.56.0 headers. No old bundled binary libraries are shipped.
- Select the BWAPI discovery table through validated SB_BWAPI_INSTANCE.

Runtime and compatibility

Use a separate writable working directory and a fresh process for every match.
The profile has no persistent bot learning state. The read/write directories
remain available for launcher infrastructure. Source review does not provide
an operating-system sandbox.

The profile is for local 1v1 legacy-unit-limit melee using ShieldBattery's
experimental BWAPI 4.4 bridge. Human skill is uncalibrated; tournament ratings
of other upstream builds do not establish this package's human difficulty.
Public competition approval is separate from local distribution.
