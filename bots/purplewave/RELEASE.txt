Changes dated 2026-09-22:
- Use the assigned working profile and fixed ShieldBattery configuration.
- Encode opponent filenames and history cells; disable visualizer auto-launch.
- Adapt String line iteration for Java 21.
- Isolate JBWAPI discovery using SB_BWAPI_INSTANCE.
- Bound the Java heap to 1024 MiB, starting at 128 MiB.
- Build with Scala 2.12.20, JNA 5.18.1, and x64 Java 21; keep runtime jars separate.

The package includes PurpleWave, JBWAPI/Java BWEM, JBWEB, JavaJPS, mjson, Scala,
JNA/JNA Platform, and Apache Commons Lang. JNA is distributed under its Apache
License 2.0 option. JNA's embedded jnidispatch native libraries include
libffi; its original copyright and permission notice is included separately
as JNA-THIRD-PARTY-NOTICES.txt. Java itself is not bundled. The original
JavaJPS README includes its MIT license and Kevin Sheehan attribution.

Patched source and rebuild materials are in source/. Exact Git revisions and
patch hashes are recorded in package.json and source/source-lock.json; dependency
jar hashes and download URLs are in source/jvm/dependencies.json.
