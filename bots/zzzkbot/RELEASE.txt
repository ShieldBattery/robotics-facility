Saved data

The bot reads optional configuration from work/bwapi-data/AI and stores opponent
history under work/bwapi-data/read and work/bwapi-data/write. The launcher must
provide a separate writable working copy for each simultaneous instance. Reset
both history folders to the empty packaged baseline to reset learning. Keep the
AI configuration folder intact. Compatible bot updates may retain this history.
The process is not sandboxed; source review does not create an OS security boundary.

Experimental compatibility

Use a Zerg slot in a 1v1 legacy-limit melee game with ShieldBattery's experimental
BWAPI 4.4 bridge. This is a staging release, not full BWAPI API conformance. The
current game bridge is available in debug builds. Public competition eligibility
is separate and has not been approved for this package.
